Why We Use CSS

Before Cascading Style Sheets existed, web developers controlled the appearance of a page by mixing presentation markup directly into the HTML. This made pages difficult to maintain and slow to update.

Advantages of CSS

Separating structure (HTML) from presentation (CSS) brings several benefits to a website.

  • Presentation for an entire website can be centralised in one document.
  • Updating the design is faster because changes only need to be made once.
  • The same HTML page can be optimised for different devices using different style sheets.
  • Pages that use CSS generally download faster than pages that repeat inline formatting.
